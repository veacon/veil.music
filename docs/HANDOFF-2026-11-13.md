## 5. 用户已确认的产品铁律（改动前必读）

1. **资料库三层焦点层级**：层级一=侧栏（Up 到「歌曲」再按 Up 回顶栏；「艺人」按 Down 进胶囊）；层级二=内容区（第一排 Up 进铅笔；Down 到底停住）；层级三=工具栏（云↔铅笔互移；框内再按 Up 回顶栏）。**Back 严格逐级：工具栏→内容区→侧栏→顶栏→退出**，不得越级。
2. **迷你胶囊**：只支持上下方向键进出，左右键不触发。
3. **歌单编辑**：选中即删；云端在线歌单整卡不可聚焦、不可删、不可进详情；全云端时 Toast「云端歌单无法删除」。
4. **删除歌曲焦点接力**：删当前行落下一首；删末行落上一首；删空回铅笔——数据更新后才落焦点。
5. **版本行**：随内容滚动挂每页最底部（播放页除外），可聚焦，Up 回内容、Down 交胶囊。
6. **版本管理**：每次测试构建末位 +1；出包后同步更新 CHANGELOG；APK 输出统一 `F:\AI\bam\.apk`；签名铁律见 §2。
7. **构建分工**：助手只出包，设备测试用户自己做。
8. **大需求流程**：先清理旧实现 → 源码自检出核对报告 → **用户确认后才写新代码**。
9. 引导页：设置项只留标题（说明文字隐藏）；简繁切换不放设置只提示；封面圆角沿用布尔；文案与设置页强绑定（冲突以设置页为准）。

## 6. 新手引导页架构（2.2.14）

- **挂载**：`AppShell.kt` 尾部——`GuideState.completed()` 为 false 时自动弹出（覆盖全屏）；若用户正在「重播设置」（Onboarding 语言流程），等其结束再弹（先语言后引导）。
- **预览区（55%）**：页 1/2 = 播放页预览（封面列 + 歌词列）；页 3 = 首页预览（顶栏条 + AlbumCard 卡片流 + 迷你胶囊）。
  - 数据全部来自 `GuideDemoData`（assets 封面 `file:///android_asset/guide/cover.webp` + 内置歌词 + 模拟进度时钟）——断网可用。
  - 联动全部走**真实组件与真实设置**：`artworkCorners`（圆角布尔）、Ken Burns（动态封面开关联动，本地动画）、`LyricLineRow(progress=模拟时钟)`（逐字开关控制时钟推进）、`MiniPlayerCapsule(previewSong=…)`（迷你胶囊开关 + 进度线开关联动）。
  - 预览区一切组件不可聚焦。
- **设置区（45%）**：2×2 网格，三页内容：
  - 页 1：界面语言、界面模式、动态封面、封面圆角
  - 页 2：音质、解码方式、歌词逐字播放、「简繁切换请到设置修改」提示格
  - 页 3：交叉渐变、顶部栏显示歌名、迷你播放胶囊、Apple Music 展示
  - 文案与设置页逐字一致（`tx()` 中文优先）；只留标题。
- **翻页**：仅右下角按钮（上一页/下一页/完成）按 OK 触发；切页后焦点重置到当页第一项（`LaunchedEffect(page)` + `firstItemFocus`）；方向键无法切页。
- **完成**：`GuideState.markCompleted()` → `onDone()`。
- **待办（用户已提、尚未实施的四项优化）**：
  1. 预览区外套「电视壳」外框（黑色粗边框、圆角、阴影立体感），App 画面以画中画呈现；壳与内部画面全部不可聚焦；
  2. 下半设置区大背景与每张设置卡片背景/圆角，严格复用系统设置页的主题代码（`SettingsSection` 卡片 = `adaptive(0xFFF5F5F7, 0xFF222225)` + `RoundedCornerShape(14.dp)`）；
  3. 精简设置项：页 1 删「界面语言/界面模式」只留动态封面+封面圆角；页 2 删简繁提示格只留音质/解码/逐字；页 3 四项不变；
  4. 第三页强联动：关闭「迷你播放胶囊」开关时，预览区底部胶囊同步彻底消失（建议 `AnimatedVisibility`），开启再显示。
